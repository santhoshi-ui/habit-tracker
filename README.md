\# Habit Tracker



A simple habit tracker that remembers your habits and counts your daily streaks.



\*\*Live demo:\*\* https://santhoshi-ui.github.io/habit-tracker/



\## Features



\- Add and delete habits

\- Tick a habit for today

\- Streak counter for days in a row

\- Saves your data in the browser, so it is still there after a refresh



\## Built with



\- HTML

\- CSS

\- JavaScript (localStorage, Date)



\## What I learned



\- Building a page with HTML, CSS and JavaScript

\- Saving data with localStorage

\- Working with dates to calculate streaks

\- Using Git and GitHub Pages to publish a project
